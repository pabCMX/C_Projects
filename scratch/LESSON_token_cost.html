1. What You Are Building

The project is a command-line program. You give it a CSV file and a month. It reads the file, ignores rows from other months, calculates a dollar cost for each matching row, adds the rows together by model, and prints a summary.

Example final use

cd ~/dev/C_Projects/scratch
make aiTokenCostCalculator.exe
./build/aiTokenCostCalculator.exe ~/Downloads/usage-events-2026-06-18.csv 2026 6

Inputs and output

Thing Meaning
~/Downloads/usage-events-2026-06-18.csv The CSV export from Cursor.
2026 The year you want to count.
6 The month you want to count. June is 6, not 06.
Printed report Total cost, per-model costs, token totals, and skipped unknown model rows.

Important learning goal: this project uses concepts from later C chapters: strings, arrays, structs, file input, helper functions, and standard library functions. That is okay. Treat it as a guided preview of real C programming, not as proof that you were supposed to know all of this already.

3. Understand the CSV Shape

CSV means comma-separated values. Each row is one event. Each comma usually moves you to the next field. The program only needs a few columns from each row.

The columns this project cares about

Field index Column meaning Example
0 Date 2026-06-18T03:24:40.767Z
4 Model name composer-2.5-fast
6 Input tokens with cache write 1200
7 Input tokens without cache write 3400
8 Cache-read input tokens 90000
9 Output tokens 500

Small fake row

2026-06-18T03:24:40.767Z,x,x,x,composer-2.5-fast,x,1200,3400,90000,500

Read it like this: date field, three fields you do not care about, model field, one more field you do not care about, then four token fields. The x values are placeholders here only to make the field numbers line up.

Real CSV files can contain quotes. A field might look like "composer-2.5-fast" instead of composer-2.5-fast. Your parser needs to handle that before string comparisons work reliably.

4. The Whole Program in Plain English

Before learning the new C tools, keep the whole project shape in your head. Most bugs become easier when you know which stage is supposed to be responsible for what. 

get the CSV path, year, and month from argv
open the CSV file
read and ignore the header row

for each remaining line:
  split the line into fields
  parse the date from field 0
  if the date is not the requested month, skip the row
  find the pricing table entry for field 4
  convert fields 6, 7, 8, and 9 to long integers
  calculate this row's cost
  add the row's tokens and cost to that model's running totals

sort the model totals by cost
print the report

That outline is your map. Each section below teaches one piece of that map.

5. File I/O: Reading a File One Line at a Time

Up to now, you have mostly used keyboard input with scanf. File input uses a different pattern:

  • FILE * is a handle to an open file.
  • fopen(path, "r") opens a file for reading.
  • fgets(line, sizeof(line), input) reads one line into a character array.
  • fclose(input) closes the file when you are done.

Tiny complete program: count lines

#include <stdio.h>

int main(void) {
  const char *path = "/home/phantompc/Downloads/usage-events-2026-06-18.csv";

  FILE *input = fopen(path, "r");
  if (input == NULL) {
    printf("Could not open %s\n", path);
    return 1;
  }

  char line[8192];
  int lines = 0;

  while (fgets(line, sizeof(line), input) != NULL) {
    lines++;
  }

  fclose(input);

  printf("Read %d lines\n", lines);
  return 0;
}

Expected result

Read 141 lines

Your exact number might differ if the CSV export changed. The important thing is that the number is not zero and the program does not print the error message.

Skipping the header row

The first row usually contains column names, not data. Read one line before the loop: 

if (fgets(line, sizeof(line), input) == NULL) {
  printf("The file is empty\n");
  fclose(input);
  return 1;
}

while (fgets(line, sizeof(line), input) != NULL) {
  printf("%s", line);
}

Calculator connection: your current starter file already opens the CSV, skips the header, prints each remaining line, and counts those data rows. That is a good first milestone.

6. Strings: Text Stored in char Arrays

In C, a string is not a special built-in type. It is an array of char values ending with a special byte called the null terminator: '\0'. The terminator tells functions where the text stops.

Tiny complete program: print and compare strings

#include <stdio.h>
#include <string.h>

int main(void) {
  char model[64] = "composer-2.5-fast";

  printf("model = %s\n", model);
  printf("length = %zu\n", strlen(model));

  if (strcmp(model, "composer-2.5-fast") == 0) {
    printf("The model names match\n");
  }

  return 0;
}

Expected output

model = composer-2.5-fast
length = 18
The model names match

Why strcmp instead of ==?

With numbers, a == b compares values. With C strings, == does not compare the text. It compares where the arrays live in memory. Use strcmp(a, b) to compare the characters.

Function Use
strlen(s) Counts characters before '\0'.
strcmp(a, b) Returns 0 when strings contain the same text.
strncpy(dest, src, n) Copies text into a fixed-size array. You still need to ensure '\0'.
strtol(s, NULL, 10) Converts text like "1234" into a long.

Safe fixed-buffer copy pattern

char name[64];

strncpy(name, "composer-2.5-fast", sizeof(name) - 1);
name[sizeof(name) - 1] = '\0';

The sizeof(name) - 1 leaves room for the null terminator. The final assignment guarantees the string is terminated even if the source text was too long.

Calculator connection: model names come from the CSV as strings. Pricing lookup is mostly a loop plus strcmp.

7. Command-Line Arguments: Let the User Choose the File

A normal main(void) ignores command-line arguments. To read arguments, write main this way: 

int main(int argc, char *argv[])
  • argc is the argument count.
  • argv is an array of strings.
  • argv[0] is the program name.
  • argv[1] is the first value typed after the program name.

Tiny complete program: inspect arguments

#include <stdio.h>

int main(int argc, char *argv[]) {
  printf("argc = %d\n", argc);

  for (int i = 0; i < argc; i++) {
    printf("argv[%d] = %s\n", i, argv[i]);
  }

  return 0;
}

Run it with arguments

gcc -std=c23 -Wall -Wextra -pedantic -g lesson_practice.c -o build/lesson_practice.exe
./build/lesson_practice.exe usage.csv 2026 6

Expected output shape

argc = 4
argv[0] = ./build/lesson_practice.exe
argv[1] = usage.csv
argv[2] = 2026
argv[3] = 6

Strict usage for the calculator

if (argc != 4) {
  printf("Usage: %s <csv-path> <year> <month>\n", argv[0]);
  return 1;
}

Start strict. Require the file path, year, and month. Optional defaults using <time.h> can come later, after the required-argument version works.

8. Structs: Group Related Values

A struct lets you create one value that contains several smaller values. For this project, a model has four prices: normal input, cache-write input, cache-read input, and output. Those prices belong together.

Tiny complete program: one pricing struct

#include <stdio.h>

typedef struct {
  double input_no_cache;
  double input_cache_write;
  double input_cache_read;
  double output;
} Pricing;

int main(void) {
  Pricing composer = {
      .input_no_cache = 3.00,
      .input_cache_write = 3.00,
      .input_cache_read = 0.50,
      .output = 15.00,
  };

  printf("Normal input: $%.2f per million\n", composer.input_no_cache);
  printf("Output:       $%.2f per million\n", composer.output);

  return 0;
}

New syntax explained

Syntax Meaning
typedef struct { ... } Pricing; Creates a new type name, Pricing.
.output = 15.00 A designated initializer. It puts 15.00 into the output field.
composer.output Accesses one field using the dot operator.

Calculator connection: each model has a Pricing value. The cost formula reads fields from that struct instead of juggling four separate variables.

9. Arrays of Structs: Build a Pricing Table

One Pricing stores rates for one model. The calculator needs several models. The natural shape is an array where each element stores the model name plus its prices.

Tiny complete program: pricing lookup

#include <stdio.h>
#include <string.h>

typedef struct {
  double input_no_cache;
  double input_cache_write;
  double input_cache_read;
  double output;
} Pricing;

typedef struct {
  char name[64];
  Pricing rates;
} ModelPricing;

int main(void) {
  static const ModelPricing table[] = {
      {
          .name = "composer-2.5-fast",
          .rates = {
              .input_no_cache = 3.00,
              .input_cache_write = 3.00,
              .input_cache_read = 0.50,
              .output = 15.00,
          },
      },
      {
          .name = "gpt-5.5-medium",
          .rates = {
              .input_no_cache = 5.00,
              .input_cache_write = 5.00,
              .input_cache_read = 0.50,
              .output = 30.00,
          },
      },
  };

  const char *wanted = "gpt-5.5-medium";
  size_t count = sizeof(table) / sizeof(table[0]);

  for (size_t i = 0; i < count; i++) {
    if (strcmp(wanted, table[i].name) == 0) {
      printf("%s output costs $%.2f per million\n",
             table[i].name, table[i].rates.output);
    }
  }

  return 0;
}

Important pieces

  • static const means this table is fixed program data.
  • sizeof(table) / sizeof(table[0]) calculates the number of array elements.
  • table[i].rates.output means: array element, then nested struct field.

If the model name from the CSV has quotes or a trailing newline, strcmp will not match. Clean the field before lookup.

10. CSV Parsing: Split One Line into Fields

The tempting solution is strtok(line, ","). That can work for very simple CSV, but real CSV allows quoted fields. A comma inside quotes is data, not a separator.

For this project, use a small parser that walks the line one character at a time. It stores pointers to the start of each field and edits the original line by replacing separators with '\0'.

The core idea

Before:
line = "date,x,x,x,model,x,1200,3400,90000,500"

After splitting:
fields[0] points to "date"
fields[4] points to "model"
fields[6] points to "1200"
fields[9] points to "500"

Tiny complete program: split a simple line

#include <stdio.h>

int split_simple_csv(char *line, char *fields[], int max_fields) {
  int count = 0;
  char *cursor = line;

  while (*cursor != '\0' && count < max_fields) {
    fields[count] = cursor;
    count++;

    while (*cursor != '\0' && *cursor != ',' && *cursor != '\n') {
      cursor++;
    }

    if (*cursor == ',' || *cursor == '\n') {
      *cursor = '\0';
      cursor++;
    }
  }

  return count;
}

int main(void) {
  char line[] = "2026-06-18,x,x,x,composer-2.5-fast,x,1200,3400,90000,500";
  char *fields[32];

  int count = split_simple_csv(line, fields, 32);

  printf("field count = %d\n", count);
  printf("date  = %s\n", fields[0]);
  printf("model = %s\n", fields[4]);
  printf("out   = %s\n", fields[9]);

  return 0;
}

Expected output

field count = 10
date  = 2026-06-18
model = composer-2.5-fast
out   = 500

Adding quote handling

The full reference version handles quotes by checking whether a field starts with ". If it does, the parser advances past the opening quote and stops at the closing quote instead of stopping at commas inside the quoted field. 

if (*cursor == '"') {
  fields[count - 1] = cursor + 1;  // skip the opening quote
  cursor++;

  while (*cursor != '\0' && *cursor != '"') {
    cursor++;
  }

  if (*cursor == '"') {
    *cursor = '\0';                // end the field at the closing quote
    cursor++;
  }

  if (*cursor == ',') {
    cursor++;
  }
}

Calculator connection: after splitting, the row-processing code can say fields[4] for the model and fields[9] for output tokens. That is much clearer than manually counting commas every time.

11. Dates and Filtering

The date text looks long, but the calculator only needs year and month: 2026-06-18T03:24:40.767Z.

Tiny complete program: parse year, month, and day

#include <stdio.h>

int main(void) {
  const char *date_text = "2026-06-18T03:24:40.767Z";
  int year = 0;
  int month = 0;
  int day = 0;

  int parsed = sscanf(date_text, "%d-%d-%d", &year, &month, &day);

  if (parsed != 3) {
    printf("Could not parse date\n");
    return 1;
  }

  printf("year=%d month=%d day=%d\n", year, month, day);

  if (year == 2026 && month == 6) {
    printf("This row belongs in the June 2026 report\n");
  }

  return 0;
}

Expected output

year=2026 month=6 day=18
This row belongs in the June 2026 report

The format string "%d-%d-%d" reads three integers separated by hyphens. It stops after the day because the format string does not ask for the time portion.

Row filter pattern

if (year != filter_year || month != filter_month) {
  continue;
}

In a loop, continue means "skip the rest of this loop body and move to the next row." That is perfect for ignoring rows from the wrong month.

12. Converting Token Fields from Text to Numbers

CSV fields are text. The token field "90000" is not a number until you convert it. Use strtol from <stdlib.h> to convert string text to a long.

Tiny complete program: parse token counts

#include <stdio.h>
#include <stdlib.h>

int main(void) {
  const char *cache_read_text = "90000";
  long cache_read = strtol(cache_read_text, NULL, 10);

  printf("cache_read = %ld\n", cache_read);
  printf("double it = %ld\n", cache_read * 2);

  return 0;
}

Expected output

cache_read = 90000
double it = 180000

Why long?

Token counts can become large. A long gives you more room than an int on typical 64-bit systems. Use %ld when printing a long.

If a field is empty, strtol("", NULL, 10) returns 0. That is useful for this project, because an empty token field can reasonably mean no tokens for that category.

13. Cost Math

Model prices are given as dollars per million tokens. That means this: 

cost = tokens * price_per_million / 1000000.0

The .0 matters because it makes the division floating-point division. Since cost is a double, keep the formula in double math.

Tiny complete program: calculate one row

#include <stdio.h>

typedef struct {
  double input_no_cache;
  double input_cache_write;
  double input_cache_read;
  double output;
} Pricing;

int main(void) {
  Pricing composer = {
      .input_no_cache = 3.00,
      .input_cache_write = 3.00,
      .input_cache_read = 0.50,
      .output = 15.00,
  };

  long cache_write = 1200;
  long no_cache = 3400;
  long cache_read = 90000;
  long output = 500;

  double cost = (cache_write * composer.input_cache_write
               + no_cache * composer.input_no_cache
               + cache_read * composer.input_cache_read
               + output * composer.output) / 1000000.0;

  printf("row cost = $%.4f\n", cost);

  return 0;
}

Expected output

row cost = $0.0663

Long-context pricing

Some models have a higher price when one event uses more than a certain number of input tokens. For gpt-5.5-medium, if cache_write + no_cache + cache_read is greater than 272000, use the long-context rates for that one row. 

long total_input = cache_write + no_cache + cache_read;

if (total_input > 272000) {
  printf("Use long-context rates for this row\n");
}

Do not apply the surcharge to the whole month just because one row crosses the threshold. Decide row by row.

14. Aggregation: Add Many Rows into Per-Model Totals

The CSV has many rows. The report should not print one line per CSV row. It should print one line per model. That means you need running totals.

Stats struct

typedef struct {
  char name[64];
  int events;
  long cache_write;
  long no_cache;
  long cache_read;
  long output;
  double cost;
} ModelStats;

Tiny complete program: add rows by model

#include <stdio.h>
#include <string.h>

typedef struct {
  char name[64];
  int events;
  double cost;
} ModelStats;

int main(void) {
  ModelStats stats[8] = {0};
  int stats_count = 0;

  const char *model_name = "composer-2.5-fast";
  double row_cost = 0.0663;

  int found = -1;
  for (int i = 0; i < stats_count; i++) {
    if (strcmp(stats[i].name, model_name) == 0) {
      found = i;
      break;
    }
  }

  if (found == -1) {
    found = stats_count;
    stats_count++;
    strncpy(stats[found].name, model_name, sizeof(stats[found].name) - 1);
    stats[found].name[sizeof(stats[found].name) - 1] = '\0';
  }

  stats[found].events++;
  stats[found].cost += row_cost;

  printf("%s: %d event, $%.4f\n",
         stats[found].name, stats[found].events, stats[found].cost);

  return 0;
}

Why initialize with {0}?

ModelStats stats[8] = {0}; starts the array with zeros. That means event counts, token counts, costs, and the first character of each name all begin empty.

Calculator connection: every matching CSV row goes through this same pattern: find the model's stats row, create one if needed, then add this row's numbers to it.

15. Sorting: Optional Report Polish with qsort

Sorting is not required for a correct calculator. It only makes the final report nicer by putting the highest-cost model first.

Comparator shape

int compare_by_cost(const void *left, const void *right) {
  const ModelStats *a = left;
  const ModelStats *b = right;

  if (a->cost < b->cost) {
    return 1;
  }
  if (a->cost > b->cost) {
    return -1;
  }
  return 0;
}

Calling qsort

qsort(stats, stats_count, sizeof(stats[0]), compare_by_cost);

The comparator receives void * pointers because qsort is generic. You convert them back to ModelStats * so you can read the cost field.

Add sorting after the unsorted report is correct. Sorting can hide aggregation bugs because the rows move around.

16. Recommended Build Order

Build this in small working stages. Each stage should compile and prove one new thing.

Stage Goal Temporary output that proves it works
1 Open the CSV and count lines. Read 141 lines or whatever your export contains.
2 Skip the header row. The first printed row starts with a real date, not column names.
3 Split one hard-coded CSV line. model=composer-2.5-fast output=500.
4 Split real file rows. Print fields[0], fields[4], and fields[9].
5 Parse dates and filter by month. Print a count of rows matching 2026-06.
6 Look up pricing by model name. Print model plus one rate, such as output price.
7 Convert token fields and calculate one row cost. Print row cost = ... with several decimals.
8 Aggregate per model. Print each model's events and total cost.
9 Use command-line arguments. The same executable works with different paths/months.
10 Sort and format the final report. The report is readable and sorted by cost.

Compile often

make aiTokenCostCalculator.exe

Run often

./build/aiTokenCostCalculator.exe ~/Downloads/usage-events-2026-06-18.csv 2026 6

If a stage fails, stop there. Do not add the next feature until the current feature produces a believable temporary print.

17. Debugging Checklist

Debug from the outside inward. First prove the file is being read. Then prove fields are split. Then prove dates, numbers, pricing, and totals.

Temporary prints worth using

printf("raw line: %s", line);
printf("field_count=%d\n", field_count);
printf("date=[%s] model=[%s] output=[%s]\n", fields[0], fields[4], fields[9]);
printf("year=%d month=%d\n", year, month);
printf("cw=%ld nc=%ld cr=%ld out=%ld\n",
       cache_write, no_cache, cache_read, output);
printf("row cost = %.8f\n", cost);

Common bug patterns

Symptom Likely cause
Program cannot open the file. The path is wrong, quoted incorrectly, or the file is not where you think it is.
First row fails date parsing. You forgot to skip the header.
Model lookup always fails. The model field still has quotes, spaces, or a newline.
Costs are zero or too small. Token fields were not converted correctly, or integer division slipped into the formula.
Month filter finds no rows. The parsed month is wrong, the requested month is wrong, or date parsing failed.
Duplicate model rows appear. The aggregation lookup is not finding an existing stats row before appending.

Debugging habit: print values in square brackets, like model=[%s]. That makes hidden spaces, empty strings, and leftover quotes easier to see.
